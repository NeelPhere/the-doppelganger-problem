# The Doppelgänger Problem

*Distinguishing visually similar microstructures using PCA when simple descriptors fail.*
---

## Overview

This project investigates whether only simple scalar descriptors are sufficient to distinguish between two physically differnet families of microstructures. Thus demonstrating the necessity of full field analysis using Principal Component Analysis (PCA).

The term used my me *“Doppelgänger Problem”* refers to the phenomenon where microstructures generated by vastly different physical processes appear statistically similar when described using low dimensional features.

---
## Objectives

* Evaluate the effectiveness of simple scalar descriptors (e.g: interface density)
* Demonstrate overlaping properties between microstructure families in low dimensional space
* Apply PCA to capture spatial correlations in full field data
* Showing how higher dimensional representations helps us in separation

---

## Thought Process

### 1. Scalar Descriptor Analysis

We begin with a single physically meaningful descriptor: **interface density**,  
which quantifies the amount of phase boundary per unit area.

This is chosen as a minimal representation and also to test whether low-dimensional summaries can distinguish between microstructure families.

### 2. Limitation of Simple Features

Although interface density captures structural information, the distributions of the two families have overlap which is quite noticeable.

Thus indicating that scalar descriptors fail to capture **spatial correlations**, which are important for distinguishing underlying evolution mechanisms (physics).

---

### 3. Full field representation

To incorporate spatial information:

* Microstructure images are flattened into vectors
* The dataset is **centered** by subtracting the mean image
* PCA (via SVD) is applied to extract dominant modes

This enables analysis of structural variations beyond simple summaries.

---
## Key insight

Microstructures can share similar global statistics while differing in their spatial organization.
These differences are not captured by scalar descriptors but emerge when we use full field representations. How well these differences can be quantified has to be answered by this project.
